# Zentry

Zentry is a Django-based productivity and social web app.  

## Features
- Gmail OAuth integration (read & send emails)
- Daily tasks (solo/group with calendar and points)
- Notes, journals, and vision board
- Messaging and notifications
- User profiles with bio, points, and achievements
